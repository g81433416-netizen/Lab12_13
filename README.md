## Описание проекта

Консольное приложение для управления библиотекой.

### Возможности:
- Добавление книг
- Выдача книг
- Возврат книг
- Поиск по автору
- Просмотр доступных книг
- Статистика

---

## Структура проекта

### Book
Содержит информацию о книге.

### Library
Управляет коллекцией книг.

### LibraryService
Реализует бизнес-логику.
